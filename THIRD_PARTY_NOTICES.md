# Avisos de terceiros

## QDiskInfo

RustDiskInfo é um projeto independente inspirado em QDiskInfo, de edisionnano, distribuído sob GNU GPL versão 3. O projeto original está em https://github.com/edisionnano/QDiskInfo.

## smartmontools / smartctl

A instalação inclui uma cópia do executável smartctl encontrado no sistema de build. smartctl faz parte do projeto smartmontools e é distribuído sob GNU GPL versão 2 ou, a critério do usuário, qualquer versão posterior. Código-fonte e licença: https://github.com/smartmontools/smartmontools
